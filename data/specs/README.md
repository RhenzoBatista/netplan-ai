Put the 3GPP specification PDFs here, then run `python -m netplan.cli ingest`.

Suggested Release 18 documents (free at https://www.3gpp.org/specifications or the ETSI mirror):

- TS 38.300 NR overall description
- TS 38.211 Physical channels and modulation (numerology)
- TS 38.213 Physical layer procedures for control (SSB, TDD patterns)
- TS 38.331 RRC (timers such as T310, N310)
- TS 38.101-1 UE radio transmission and reception, FR1 (bands)
- TS 23.501 System architecture (network slicing, SNPN)
